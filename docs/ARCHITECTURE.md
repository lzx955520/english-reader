# 初版实现说明

## 技术取舍

Electron 负责 Windows 窗口、网络请求、文件对话框及系统加密。React + TypeScript 渲染界面，lucide-react 提供图标。渲染器启用 sandbox / contextIsolation，无 Node 集成，不直接访问网络、文件或密钥；CSP 限制脚本与资源为本地文件，所有用户文本按文本渲染，模型输出不作为 HTML。

SQLite 使用 sql.js（SQLite WASM），不是模拟数据库。主进程串行执行事务，提交后通过临时文件、fsync 和 rename 保存完整 SQLite 文件；单实例锁避免两个进程写同一文件。这个选择省去原生模块跨 Windows ABI 的编译，便于云端交叉打包。当前每次更新导出整个数据库，适合初版个人小型库；海量材料应迁移到原生 SQLite 事务写盘，或增加批量持久化，不能当成无限规模设计。

## 推荐与内容

`electron/network.ts` 调用 MediaWiki API：

1. `action=query&list=categorymembers&cmtitle=Category:Published&cmsort=timestamp&cmdir=desc` 获取候选，同时通过 siteinfo rightsinfo 核对当前来源许可，只接受明确的 CC BY 4.0 / 2.5。
2. `action=parse&pageid=…&prop=text|wikitext` 获取 HTML 正文与日期模板；分类时间只用于候选顺序，**不当成发表日期**。
3. 从 `{{date|…}}` 解析发表日期。缺失 / 异常日期、撤稿 / 争议标记、超过 30 天或未来日期、正文过短 / 过长均不接收。
4. Cheerio 提取段落、删除导航、表格、脚注等；新闻正文不改写，不抓取图片。每轮扫描最多 10 篇候选、收录最多 3 篇，启发式优先适合精读的长度与难度。
5. SQLite 按稳定页面 ID 和来源 URL 去重。获取失败不删除材料，也不设置当天成功更新时间。没有材料时显示原因，经典离线材料独立分类。

启动时检查，当地日期变化定时检查，渲染器 online 事件触发强制检查；手动更新可强制重试。网络请求使用 Electron net.fetch，让桌面系统网络和代理设置生效；失败后后台重试冷却 10 分钟，手动 / 联网恢复可立即重试。每个新闻请求 20 秒超时，正文最多 3 MB。用户取消通过 AbortController 传播；同时点击共享唯一刷新任务。

联网来源协议已用 fixture 验证，**当前云端无法访问来源，未宣称真实网络抓取通过**。Wikinews 更新频率有限，无内容时不能保证每日新文章。添加新来源之前必须核实全文再利用许可、作者署名及访问条件；不能把网站“可以浏览”当成“可以缓存分发”。

## 词典、例句和复习

48,185 个词条从固定版本 ECDICT 中按考试标签 / Oxford 核心 / BNC、COCA 前 40,000 筛选。另建词形映射表；查询优先原词，随后匹配派生形式。原始英汉释义、音标与词性保留，可能有未收录项 / 空字段。短语可查询，也可收藏；未收录不会杜撰定义。

卡片 ID 为规范化单词 + 文章 ID 的 SHA-256，同一材料重复点击返回已有卡片。保存例句与来源，不只保存词语。复习采用 SM-2 思路：首次成功 1 天，第二次 6 天，随后根据 ease 和评分更新；困难 / 轻松调整成熟卡间隔，忘记则 10 分钟重学。每次更新版本号，重复提交旧版本不会二次推进；未到期不允许评分。排期使用本地日历加天，保存 ISO 时间。

## 模型接口与付费边界

每个功能独立保存提供商、HTTPS 基础地址、模型名与系统加密密钥。默认配置：

| 功能 | 默认模型 | 请求用途 |
| --- | --- | --- |
| 语境 / 短语 | deepseek-chat | 释义、搭配和语境解释 |
| 内容筛选 | deepseek-chat | 只评估已缓存的真实新闻元数据 |
| 复杂语法 | deepseek-reasoner | 主干、从句、修饰、指代和中文意思 |

OpenAI 兼容协议使用 `POST {baseUrl}/chat/completions`、Bearer authorization、messages、stream=false，输出上限 1800 token，90 秒超时，不自动重试。DeepSeek 基础地址默认 `https://api.deepseek.com`，模型名可编辑。基础地址、接口路径及默认模型标识已对照 DeepSeek 官方组织维护的集成文档核查，记录见 API_REFERENCES.md。主 API 文档地址 `https://api-docs.deepseek.com/` 当前云端被代理策略拒绝；不能把兼容协议 mock 通过当成当前服务可用性或真实调用核验。未录入任何真实密钥、未消费 API。

默认由主进程原生对话框显示请求快照、数据、提供商、模型和完整接收接口，并取得单次授权；渲染器的 `approved` 标记不提供授权。侧栏“本次 AI 授权”经主进程一次性披露三个功能的数据范围、全部接口及费用后，可覆盖同一应用进程内用户主动点击的请求。授权只存在主进程内存，不写入数据库、设置或备份；页面重载读取主进程状态，不自动授予。关闭开关、提供商 / 模型 / 接口 / 密钥变化、恢复备份和退出都会撤销授权并取消正在进行的 AI 请求。修订号阻止撤销或配置变化后仍在等待的对话框重新授予权限；请求发送前再次核对修订号。AI 网络请求拒绝重定向，避免发送到未披露的接收接口。长句 / 原文段落或新闻元数据作为被引用材料传递，不执行其内部指令。AI 不改写文章或复习数据；用户可以把解释作为收藏释义。取消本地等待不保证服务端停止计费，界面明确提示。

密钥仅通过 safeStorage 写入加密文件；Linux basic_text 后端被明确拒绝。Windows 使用 DPAPI，密钥不返回渲染器、日志或备份。若无法解密，基础界面仍可打开，需重新录入密钥。对系统本身已被攻陷的情况不承诺保护。

## 备份与恢复

JSON 格式有独立 format / version，使用 Zod 验证完整类型、尺寸上限、记录唯一性与来源引用；全部验证通过才在事务内替换。界面确认后先写入恢复前安全备份。50 MB 文件上限，不解析不受限大文件。导出 CSV 对引号、换行及公式前缀做转义，带 UTF-8 BOM。模型地址等非密钥设置包含在备份内，密钥完全排除。

测试中的 READER_E2E / READER_TEST_OFFLINE 只在未打包开发运行时有效；生产包不启用测试处理器。测试不能向用户推荐 fixture 新闻。
